Create `BackEnd/api/evaluation/monte_carlo.py` with:

1. **`MCConfig` dataclass**:
   - `trainer: str` -- trainer type
   - `topology: str` -- topology name
   - `n_runs: int = 10` -- number of MC repetitions
   - `base_seed: int = 42` -- first seed (subsequent: base_seed + i)
   - `ranked: bool = True`
   - `horizon: int = 450`
   - `weights_path: str = None` -- if None, auto-resolved

2. **`MCAggregatedResult` dataclass**:
   - `config: MCConfig`
   - `individual_results: list[dict]` -- each run's metrics as dict (from metrics_to_dict)
   - `n_completed: int` -- how many runs succeeded
   - `n_failed: int` -- how many runs failed (with error messages)
   - `aggregated: dict` -- aggregated statistics (see below)
   - `errors: list[str]` -- error messages from failed runs

3. **`_aggregate_metrics(metrics_list: list[TrialMetrics]) -> dict`**:
   - Takes list of TrialMetrics from successful runs
   - For each numeric field (avg_waiting_time, avg_travel_time, throughput, mean_reward, total_comm_cost):
     - Compute `mean`, `std`, `min`, `max`
     - Compute 95% confidence interval: `mean +/- 1.96 * std / sqrt(n)`
   - Returns dict structured as:
     ```python
     {
       "avg_waiting_time": {"mean": float, "std": float, "ci_95_lower": float, "ci_95_upper": float, "min": float, "max": float},
       "avg_travel_time": {"mean": ..., "std": ..., ...},
       "throughput": {"mean": ..., "std": ..., ...},
       "mean_reward": {"mean": ..., "std": ..., ...},
       "total_comm_cost": {"mean": ..., "std": ..., ...},
     }
     ```
   - Use `import math; math.sqrt()` and `statistics.mean, statistics.stdev` from stdlib (avoid numpy dependency in this module)

4. **`run_monte_carlo(config: MCConfig, on_progress: callable = None) -> MCAggregatedResult`**:
   - Resolve weights_path if not provided: `resolve_weights_path(config.trainer, config.topology, config.ranked)` (skip for fixed-time/max-pressure)
   - Loop `n_runs` times with seeds `config.base_seed + i` for i in range(n_runs)
   - For each run:
     - Call `run_trial(config.trainer, config.topology, seed, config.ranked, weights_path, config.horizon)`
     - Call `compute_trial_metrics(trial_result)`
     - Append metrics_to_dict(metrics) to individual_results
     - On success, increment n_completed
     - On exception, log warning, increment n_failed, append error string
     - Call `on_progress(completed=i+1, total=config.n_runs, config=config)` if callback provided
   - After all runs, call `_aggregate_metrics(successful_metrics_list)`
   - Return MCAggregatedResult

5. **`run_full_campaign(trainers: list[str] = None, topologies: list[str] = None, n_runs: int = 10, ranked: bool = True, on_progress: callable = None) -> list[MCAggregatedResult]`**:
   - If trainers is None, use TRAINERS (all 5)
   - If topologies is None, use TOPOLOGIES (all 3)
   - For each trainer x topology combination:
     - Create MCConfig
     - Call run_monte_carlo(config, on_progress)
     - Append result
   - Returns list of MCAggregatedResult (up to 15 entries for 5x3)
   - Total trials: 5 trainers x 3 topologies x 10 runs = 150

6. **`campaign_to_dict(results: list[MCAggregatedResult]) -> dict`**:
   - Converts full campaign results to JSON-serializable dict
   - Structure: `{"campaign": [{"trainer": str, "topology": str, "n_runs": int, "aggregated": {...}, "individual": [...]}]}`
