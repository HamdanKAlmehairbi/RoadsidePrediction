Create `BackEnd/api/evaluation/metrics.py` with:

1. **`TripinfoMetrics` dataclass**:
   - `avg_waiting_time: float` -- mean of all tripinfo waitingTime values (seconds)
   - `avg_travel_time: float` -- mean of all tripinfo duration values (seconds)
   - `avg_depart_delay: float` -- mean of all tripinfo departDelay values (seconds)
   - `throughput: float` -- completed_trips / spawned_trips ratio (0.0-1.0)
   - `completed_trips: int` -- number of tripinfo entries (completed vehicles)
   - `total_waiting_time: float` -- sum of all waitingTime values
   - `total_travel_time: float` -- sum of all duration values

2. **`TrialMetrics` dataclass**:
   - `tripinfo: TripinfoMetrics`
   - `mean_reward: float` -- mean of all per-TLS per-step rewards
   - `total_reward: float` -- sum of all rewards
   - `comm_costs: dict[str, int]` -- communication cost by type
   - `total_comm_cost: int` -- sum of all comm costs
   - `trainer: str`
   - `topology: str`
   - `seed: int`

3. **`compute_tripinfo_metrics(tripinfo_path: str) -> TripinfoMetrics`**:
   - Parse XML: `tree = ET.parse(tripinfo_path)`
   - For each `<tripinfo>` element, extract: `float(trip.get("waitingTime", 0))`, `float(trip.get("duration", 0))`, `float(trip.get("departDelay", 0))`
   - Count total spawned from route file or estimate as completed_trips (for now, use completed_trips as denominator -- throughput = 1.0 if all complete, adjusted in MC aggregation)
   - Compute averages, sums
   - Return TripinfoMetrics

4. **`compute_trial_metrics(trial_result: TrialResult) -> TrialMetrics`**:
   - Import `TrialResult` from `.runner`
   - Compute mean_reward: flatten all per_tls_rewards lists, take mean
   - Compute total_reward: sum all rewards
   - Parse tripinfo from trial_result.tripinfo_path using `compute_tripinfo_metrics()`
   - Sum comm_costs values for total_comm_cost
   - Return TrialMetrics

5. **`metrics_to_dict(metrics: TrialMetrics) -> dict`**:
   - Converts TrialMetrics to a JSON-serializable dict (for storage/API)
   - Recursively converts TripinfoMetrics too
   - All float values rounded to 4 decimal places

  <action>
Create `BackEnd/api/evaluation/transfer.py` with:

1. **`TransferResult` dataclass**:
   - `train_topology: str` -- topology the weights were trained on
   - `test_topology: str` -- topology evaluated on
   - `trainer: str` -- trainer type (FedRL, MARL, SARL)
   - `metrics: TrialMetrics` -- evaluation metrics on test topology
   - `is_transfer: bool` -- True if train_topology != test_topology

2. **`build_transfer_matrix(trainer_type: str, ranked: bool = True, seed: int = 42, horizon: int = 450) -> list[TransferResult]`**:
   - For each `train_topo` in TOPOLOGIES:
     - For each `test_topo` in TOPOLOGIES:
       - Find weights trained on `train_topo`: `resolve_weights_path(trainer_type, train_topo, ranked)`
       - If weights not found, skip with warning log
       - Run `run_trial(trainer_type, test_topo, seed, ranked, weights_path, horizon)`
       - Compute `compute_trial_metrics(trial_result)`
       - Append `TransferResult(train_topology=train_topo, test_topology=test_topo, trainer=trainer_type, metrics=metrics, is_transfer=(train_topo != test_topo))`
   - Return list of TransferResult objects
   - Total: up to 3x3=9 trials per trainer_type

3. **`compute_transfer_gap(results: list[TransferResult]) -> dict`**:
   - Groups results by trainer
   - For each trainer, computes:
     - `home_performance`: mean of metrics.mean_reward where is_transfer=False (diagonal)
     - `transfer_performance`: mean of metrics.mean_reward where is_transfer=True (off-diagonal)
     - `gap`: home_performance - transfer_performance (positive = degradation on transfer)
     - `gap_pct`: gap / abs(home_performance) * 100 (percentage degradation)
   - Returns dict: `{"trainer": str, "home_reward": float, "transfer_reward": float, "gap": float, "gap_pct": float}`

4. **`transfer_matrix_to_dict(results: list[TransferResult]) -> dict`**:
   - Converts to a JSON-serializable nested structure:
     ```python
     {
       "trainer": trainer_type,
       "matrix": {
         "grid-3x3": {"grid-3x3": metrics_dict, "grid-5x5": metrics_dict, ...},
         "grid-5x5": {...},
         ...
       },
       "transfer_gap": compute_transfer_gap(results)
     }
     ```
   - Uses `metrics_to_dict()` for each cell
  </action>
