Create `BackEnd/api/evaluation/runner.py` with:

1. **Imports**: `os, logging, xml.etree.ElementTree as ET, pickle, numpy as np` from stdlib; `from seal.sumo.env import SumoEnv`; `from seal import TRIPINFO_OUT_FILENAME`; `from seal.trainer.util import GLOBAL_POLICY_VAR`; `from ..training_runner import get_net_file, ensure_ray, load_weights, TOPOLOGY_MAP, TRAINED_WEIGHTS_DIR`; `from seal.trainer.communication import EDGE2TLS_POLICY, TLS2EDGE_POLICY, EDGE2TLS_ACTION, EDGE2TLS_RANK, TLS2EDGE_OBS, VEH2TLS_COMM`

2. **`TrialResult` dataclass** with fields:
   - `trainer: str` (e.g. "FedRL", "MARL", "SARL", "fixed-time", "max-pressure")
   - `topology: str` (e.g. "grid-3x3")
   - `seed: int`
   - `ranked: bool`
   - `per_tls_rewards: dict[str, list[float]]` -- mapping tls_id -> list of per-step rewards
   - `tripinfo_path: str` -- path to the tripinfo XML produced
   - `comm_costs: dict[str, int]` -- mapping comm type string -> total count
   - `total_steps: int`
   - `n_vehicles_total: int` -- number of unique vehicles seen

3. **`run_trial(trainer_type: str, topology: str, seed: int, ranked: bool = True, weights_path: str = None, horizon: int = 450) -> TrialResult`**:
   - Calls `ensure_ray()` if trainer_type is an RL type
   - Builds `env_config` dict: `{"gui": False, "net-file": get_net_file(topology), "rand_routes_on_reset": True, "ranked": ranked, "use_dynamic_seed": False, "rand_route_args": {"seed": seed}, "horizon": horizon}`
   - For RL trainers ("FedRL", "MARL", "SARL"): loads weights with `load_weights(weights_path)`, creates PPOTorchPolicy, sets weights (same pattern as `_run_traci_simulation` in simulate.py)
   - For "fixed-time": policy = None, actions will be `{agent_id: 0 for agent_id in agent_ids}` (stay in current phase)
   - For "max-pressure": policy = None, actions from `compute_max_pressure_actions(agent_ids)` (import from `..baselines.max_pressure`)
   - Creates `SumoEnv(config=env_config)`, calls `env.reset(seed=seed)`
   - Runs episode loop collecting per-TLS rewards in a `defaultdict(list)`, tracking vehicle count
   - After episode, calls `env.close()`
   - Parses tripinfo: `tree = ET.parse(TRIPINFO_OUT_FILENAME)` to extract trip count
   - Copies tripinfo to a unique path: `BackEnd/results/tripinfo/{trainer}_{topology}_{seed}.xml` using `shutil.copy2`
   - Extracts comm costs from the env's callback data if available (for RL trainers), otherwise empty dict
   - Returns `TrialResult` with all collected data

4. **`resolve_weights_path(trainer_type: str, topology: str, ranked: bool) -> str`**:
   - For "fixed-time" or "max-pressure": returns None
   - For RL trainers: scans `TRAINED_WEIGHTS_DIR/weights/{trainer_type}/{topology}/` for `ranked.pkl` or `unranked.pkl`
   - Falls back to example_weights with same pattern
   - Raises FileNotFoundError if no weights found

5. **Module-level constant** `TRAINERS = ["FedRL", "MARL", "SARL", "fixed-time", "max-pressure"]`
6. **Module-level constant** `TOPOLOGIES = list(TOPOLOGY_MAP.keys())` -- ["grid-3x3", "grid-5x5", "grid-7x7"]
