**Create `BackEnd/api/routes/evaluate.py`:**

1. **`EvaluateRequest` Pydantic model**:
   - `trainers: list[str] = None` -- if None, all 5 trainers
   - `topologies: list[str] = None` -- if None, all 3 topologies
   - `n_runs: int = 10` -- MC repetitions per config
   - `ranked: bool = True`
   - `horizon: int = 450`
   - `include_transfer: bool = False` -- whether to also run transfer matrix

2. **`POST /api/evaluate`** (status_code=202):
   - Creates job_id: `"eval_" + uuid.uuid4().hex[:8]`
   - Calls `create_job(job_id, "evaluation")`
   - Launches `asyncio.create_task(run_evaluation_job(job_id, req))`
   - Returns `{"job_id": job_id, "status": "running"}`

3. **`async def run_evaluation_job(job_id, req)`**:
   - Runs in ThreadPoolExecutor (same pattern as train.py)
   - Calls `_run_evaluation_sync(job_id, req, loop)`

4. **`def _run_evaluation_sync(job_id, req, loop)`**:
   - Gets queue from `jobs[job_id]["frames_queue"]`
   - Defines `on_progress(completed, total, config)` that puts progress frame to queue:
     `{"type": "progress", "completed": completed, "total": total, "trainer": config.trainer, "topology": config.topology}`
   - Calls `run_full_campaign(trainers=req.trainers, topologies=req.topologies, n_runs=req.n_runs, ranked=req.ranked, on_progress=on_progress)`
   - If `req.include_transfer` and any RL trainer in trainers:
     - For each RL trainer, calls `build_transfer_matrix(trainer, req.ranked)`
   - Builds final results dict using `campaign_to_dict()` and `transfer_matrix_to_dict()` if applicable
   - Adds metadata: `created_at` (ISO format), `job_id`, `status: "complete"`
   - Saves via `save_evaluation(job_id, results)`
   - Sets `jobs[job_id]["status"] = "complete"` and `jobs[job_id]["results"] = results`
   - Puts final `{"type": "complete", "job_id": job_id}` frame to queue

5. **`GET /api/evaluation/{job_id}`**:
   - First checks in-memory `jobs` dict
   - If not found or no results, tries `load_evaluation(job_id)` from disk
   - Returns full results dict or 404

6. **`GET /api/evaluations`**:
   - Calls `list_evaluations()` and returns the list
