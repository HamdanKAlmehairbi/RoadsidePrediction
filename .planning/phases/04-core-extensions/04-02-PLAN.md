<objective>
Implement cooperative reward shaping in SumoEnv so each traffic light's reward blends its local reward with the mean reward of its graph neighbors, controlled by alpha parameter.

Purpose: Cooperative reward encourages neighboring intersections to coordinate, which is a key research dimension for federated traffic signal control. Alpha=1.0 (fully selfish) preserves backward compatibility; alpha<1.0 blends in neighbor rewards.

Output: Modified SumoEnv with _get_all_rewards() method and alpha-parameterized cooperative blending.
</objective>

   Store alpha BEFORE super().__init__() because super().__init__() calls reset() which calls step logic. Actually, reward is only computed in step(), not in reset(), so order doesn't matter for correctness. But storing before super() is safer. Note: `self.alpha` must be set before `super().__init__()` since the parent's `__init__` calls `self.reset()` which calls `self._observe()` but NOT `step()`, so reward isn't computed during init. Still, set it early for safety.

2. Rename `_get_reward` to `_get_local_reward` (keep same signature and body):
   ```python
   def _get_local_reward(self, obs: np.ndarray) -> float:
       """Per-TLS local reward based on occupancy."""
       return -1 * (obs[LANE_OCCUPANCY] + obs[HALTED_LANE_OCCUPANCY])**2
   ```

3. Keep `_get_reward` as a backward-compatible wrapper that calls `_get_local_reward`:
   ```python

   ```
   This preserves the abstract method contract from AbstractSumoEnv.

4. Add `_get_all_rewards` method:
   ```python
   def _get_all_rewards(self, obs: dict) -> dict:
       """Compute rewards with optional cooperative blending.

       When alpha=1.0, returns pure local rewards (backward compatible).
       When alpha<1.0, blends local reward with mean neighbor reward.
       """
       local_rewards = {
           tls.id: self._get_local_reward(obs[tls.id])
           for tls in self.kernel.tls_hub
       }
       if self.alpha >= 1.0:
           return local_rewards

       graph = self.kernel.tls_hub.tls_graph
       cooperative_rewards = {}
       for tls in self.kernel.tls_hub:
           neighbors = graph.get(tls.id, [])
           if neighbors:
               neighbor_mean = sum(local_rewards[n] for n in neighbors) / len(neighbors)
           else:
               neighbor_mean = local_rewards[tls.id]
           cooperative_rewards[tls.id] = (
               self.alpha * local_rewards[tls.id] +
               (1.0 - self.alpha) * neighbor_mean
           )
       return cooperative_rewards
   ```

5. Modify `step()` to use `_get_all_rewards` instead of the per-TLS dict comprehension:
   Change line:
   ```python
   reward = {tls.id: self._get_reward(obs[tls.id])
             for tls in self.kernel.tls_hub}
   ```
   To:
   ```python
   reward = self._get_all_rewards(obs)
   ```

Important: The cooperative reward operates on scalar `local_rewards` (floats), NOT on raw observation arrays. This avoids any NaN/Inf issues since the obs values have already been cleaned in `_observe()` before `step()` computes reward. Actually, looking at step(): obs is computed by `_observe()` (which cleans NaN/Inf), THEN reward uses those cleaned obs values. So the reward computation is safe.
