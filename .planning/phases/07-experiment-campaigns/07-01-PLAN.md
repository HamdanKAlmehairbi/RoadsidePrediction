```python
@dataclass
class ExtensionConfig:
    name: str                          # Human label, e.g. "fedprox_mu0.1"
    trainer_type: str                  # "FedRL", "MARL", "SARL"
    topology: str                      # "grid-3x3", "grid-5x5", "grid-7x7"
    n_episodes: int = 50              # Training episodes
    n_eval_runs: int = 10             # MC evaluation runs
    base_seed: int = 42
    ranked: bool = True
    horizon: int = 450
    fedprox_mu: float = 0.0
    alpha: float = 1.0
    time_of_day: bool = False
    use_time_encoding: bool = False
    weights_path: Optional[str] = None  # If set, skip training and use these weights
```

2. `CampaignResult` dataclass:
```python
@dataclass
class CampaignResult:
    config: ExtensionConfig
    training_rewards: Optional[List[dict]] = None  # None if weights_path was provided (no training)
    evaluation: Optional[MCAggregatedResult] = None
    weights_path: Optional[str] = None
    error: Optional[str] = None
    duration_seconds: float = 0.0
```

3. `EXAMPLE_WEIGHTS_MAP` dict — maps `(trainer, topology)` tuples to absolute-safe relative paths (from BackEnd/ root):

```python
    ("SARL", "grid-3x3"): "example_weights/ICCPS/Final/SARL/grid-3x3/v3_ranked.pkl",
    ("SARL", "grid-5x5"): "example_weights/ICCPS/Final/SARL/grid-5x5/v3_ranked.pkl",
}
```
Paths are relative to `BackEnd/` directory. The script will resolve them to absolute paths using `os.path.join(BACKEND_DIR, path)`.

Create `BackEnd/scripts/run_campaign.py` — a standalone CLI script that runs experiment campaigns.

The script MUST add BackEnd to sys.path at the top:
```python
import sys, os
sys.path.insert(0, os.path.join(os.path.dirname(__file__), ".."))
```

Implement these functions:

1. `train_and_evaluate(config: ExtensionConfig, on_progress=None) -> CampaignResult`:
   - If `config.weights_path` is not None, skip training and use provided weights
   - Otherwise, call `create_trainer(trainer_type=config.trainer_type, topology=config.topology, ranked=config.ranked, n_episodes=config.n_episodes, fedprox_mu=config.fedprox_mu, alpha=config.alpha, time_of_day=config.time_of_day, use_time_encoding=config.use_time_encoding)` then `run_training_loop(trainer, n_episodes=config.n_episodes)`
   - Extract `weights_path` from training result
   - Create `MCConfig(trainer=config.trainer_type, topology=config.topology, n_runs=config.n_eval_runs, base_seed=config.base_seed, ranked=config.ranked, horizon=config.horizon, weights_path=weights_path)`
   - Call `run_monte_carlo(mc_config, on_progress=on_progress)`
   - Return `CampaignResult` with all fields populated
   - Wrap in try/except, set `result.error = str(exc)` on failure
   - Track `duration_seconds` using `time.time()` around the whole operation

2. `run_baseline_campaign(topologies=None, n_eval_runs=10, dry_run_seeds=None) -> List[CampaignResult]`:
   - Runs paper-reproduction: FedRL, MARL, SARL (with example weights via `resolve_example_weights`), plus fixed-time, max-pressure (no weights needed)
   - Defaults topologies to `["grid-3x3", "grid-5x5"]` (no grid-7x7 — no example weights)
   - For fixed-time and max-pressure, set `trainer_type` accordingly and `weights_path` to a sentinel (these don't need weights; MCConfig handles it). Actually just create MCConfig directly for baselines since they don't need training.
   - If `dry_run_seeds` is set (e.g., 2), override `n_eval_runs` to that value for smoke testing
   - Log progress: `logger.info("Campaign %d/%d: %s on %s — %d/%d runs OK", ...)`

3. `save_campaign_results(results: List[CampaignResult], campaign_name: str) -> str`:
   - Create `BackEnd/results/campaigns/{campaign_name}/` directory
   - Save `results.json` with all results serialized via `result_to_dict`
   - Save `config.json` with the list of ExtensionConfig dicts used
   - Return the directory path
   - Use `json.dump(fp, default=str, indent=2)` for safe serialization

4. `main()` with argparse CLI:
   - `--campaign` choices: `["baseline", "custom"]` (default: "baseline")
   - `--topologies` nargs="+" default `["grid-3x3", "grid-5x5"]`
   - `--n-eval-runs` type=int default=10
   - `--dry-run` type=int default=None — if set, runs only this many seeds per config (e.g., `--dry-run 2`)
   - `--output-name` default="baseline" — name for results directory
   - Calls `run_baseline_campaign()` or prints usage for custom
   - Calls `save_campaign_results()` at end
   - Prints summary: configs run, total completed/failed, output directory

Add `if __name__ == "__main__": main()` at bottom.

IMPORTANT: The script imports Python modules directly (NOT via REST API). It does NOT start the FastAPI server. It uses `from api.training_runner import ...` and `from api.evaluation.monte_carlo import ...` directly.
