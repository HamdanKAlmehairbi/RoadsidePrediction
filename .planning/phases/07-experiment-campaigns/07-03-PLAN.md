Implement these functions:

1. `load_campaign_results(campaign_dir: str) -> List[dict]`:
   - Load `{campaign_dir}/results.json` via `json.load`
   - Return the list under `results` key
   - Raise FileNotFoundError if results.json missing

2. `results_to_dataframe(campaign_results: List[dict]) -> pd.DataFrame`:
   - Flatten each result into a row with columns:
     - `name` (from config.name)
     - `trainer` (from config.trainer_type)
     - `topology` (from config.topology)
     - `fedprox_mu`, `alpha`, `time_of_day` (from config)
     - `avg_waiting_time_mean`, `avg_waiting_time_std` (from evaluation.aggregated)
     - `avg_travel_time_mean`, `avg_travel_time_std`
     - `mean_reward_mean`, `mean_reward_std`
     - `total_comm_cost_mean`, `total_comm_cost_std`
     - `n_completed`, `n_failed` (from evaluation)
   - Skip results where evaluation is None or has error
   - Return `pd.DataFrame(rows)`

3. `wilcoxon_compare(results_a: dict, results_b: dict, metric: str = "avg_waiting_time") -> dict`:
   - Extract individual metric values from `results_a["evaluation"]["individual_results"]` and `results_b["evaluation"]["individual_results"]`
   - For tripinfo metrics (avg_waiting_time, avg_travel_time), access via `r["tripinfo"][metric]`
   - For reward metrics (mean_reward), access via `r[metric]`
   - Check both have n_completed >= 8; if not, return `{"valid": False, "reason": "insufficient samples", "n_a": len(values_a), "n_b": len(values_b)}`
   - Call `scipy.stats.wilcoxon(values_a, values_b)`
   - Return `{"valid": True, "statistic": float(stat), "p_value": float(p), "significant": p < 0.05, "n": min(len(values_a), len(values_b))}`
   - Handle `ValueError` from scipy (e.g., all-zero differences) gracefully — return `{"valid": False, "reason": str(exc)}`

4. `generate_latex_table(df: pd.DataFrame, metric: str, output_path: str) -> None`:
   - Pivot table with rows = topology (or config name), columns = trainer/condition
   - Format values as `{mean:.1f} $\\pm$ {std:.1f}`
   - Write booktabs-formatted LaTeX with `\toprule`, `\midrule`, `\bottomrule`
   - Use `\begin{tabular}`, NOT pandas `.to_latex()`
   - Write to output_path as plain text file

5. `plot_comparison_bar(df: pd.DataFrame, metric: str, output_path: str, group_by: str = "name") -> None`:
   - Grouped bar chart with 95% CI error bars
   - CI computed as `1.96 * std / sqrt(n)` where n is from `n_completed` column (default 10)
   - Use matplotlib, NOT seaborn (fewer dependency issues)
   - Set `figsize=(10, 5)`, `dpi=150`
   - Add legend, axis labels (metric name with units " (s)" for time metrics)
   - Call `plt.tight_layout()` then `plt.savefig(output_path)`
   - Call `plt.close()` to free memory

6. `generate_all_outputs(campaign_dir: str, output_dir: str = None) -> None`:
   - If output_dir is None, default to `BackEnd/results/figures/`
   - Create output_dir if it doesn't exist
   - Load results, build DataFrame
   - Generate LaTeX tables for avg_waiting_time and avg_travel_time
   - Generate bar charts for avg_waiting_time, avg_travel_time, mean_reward
   - Log all generated file paths

7. `main()` with argparse:
   - `--campaign-dir` required — path to campaign results directory
   - `--output-dir` default=None — path for figures output
   - `--metric` default="avg_waiting_time" — metric for single-chart mode
   - `--format` choices=["all", "table", "chart"] default="all"
   - Calls `generate_all_outputs()` or individual functions

Add `if __name__ == "__main__": main()` at bottom.

Use `import matplotlib; matplotlib.use("Agg")` BEFORE importing pyplot to ensure non-interactive backend (no display needed).
