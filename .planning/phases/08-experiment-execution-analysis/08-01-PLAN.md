    **Part B: Add 6 new functions to generate_tables.py (per D-10 through D-16)**

    Add these functions AFTER existing `generate_all_outputs()`:

    1. `plot_convergence_curves(campaign_results: list, output_path: str, window: int = 5) -> None`:
       - Iterate results, skip those with `training_rewards is None` or empty
       - Extract per-episode reward: `[r.get("mean_reward", r) if isinstance(r, dict) else r for r in rewards_data]`
       - Plot raw values as faint (alpha=0.2, linewidth=0.8)
       - Plot smoothed with `np.convolve(values, np.ones(window)/window, mode="valid")` as solid line (linewidth=1.8)
       - Label = config name, xlabel="Episode", ylabel="Mean Episode Reward", title="Training Convergence"
       - `plt.close()` after `plt.savefig(output_path, dpi=150)`
       - Return early (with plt.close()) if 0 configs have training_rewards

    2. `select_best_config_name(campaign_results: list, metric: str = "avg_waiting_time") -> str`:
       - Call `results_to_dataframe(campaign_results)`
       - Find row with minimum `{metric}_mean`
       - Return `df.loc[df[f"{metric}_mean"].idxmin(), "name"]`
       - Return `""` if df is empty or column missing

    3. `plot_combined_comparison(baseline_results: list, ablation_map: dict, output_path: str, metric: str = "avg_waiting_time") -> None`:
       - `ablation_map` = {"FedProx": [...results...], "Cooperative": [...], "ToD": [...]}
       - Select baseline FedRL row from baseline_results
       - For each ablation, call `select_best_config_name()` and extract that row
       - Build a small DataFrame with columns [name, trainer, topology, metric_mean, metric_std, n_completed]
       - Call `plot_comparison_bar()` on it (reuse existing function)
       - `plt.close()` after

    4. `plot_per_topology(campaign_results: list, topology: str, metric: str, output_path: str) -> None`:
       - Call `results_to_dataframe(campaign_results)`
       - Filter: `df = df[df["topology"] == topology]`
       - Call `plot_comparison_bar(df, metric, output_path)`

    5. `generate_ablation_table_with_pvalues(campaign_results: list, baseline_name: str, metric: str, output_path: str) -> None`:
       - Build DataFrame from results
       - Find baseline result dict by matching config.name == baseline_name
       - For each non-baseline result, call `wilcoxon_compare(baseline_result, other_result, metric)`
       - Generate LaTeX table with columns: Config | Mean +/- Std | p-value
       - p-value column: show `p={value:.3f}` if valid, `n/a` if not valid
       - Bold the lowest mean value in the mean column using `\textbf{}`
       - Use booktabs formatting matching existing `generate_latex_table()` pattern

    6. `generate_combined_extensions_table(baseline_results: list, ablation_map: dict, metric: str, output_path: str) -> None`:
       - For baseline: extract FedRL row
       - For each ablation: call `select_best_config_name()`, extract that row
       - Build a table: Config | Avg Wait Time (mean +/- std) | Improvement vs Baseline
       - Bold the best (lowest) value using `\textbf{}`
       - Use booktabs formatting
